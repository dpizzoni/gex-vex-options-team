# 6. Protocolo de Auto-Corrección Global

Regla absoluta: **Nunca falles dos veces por lo mismo.**

Cuando detectes o el usuario reporte un error repetido:

Ciclo obligatorio:
1. Diagnosticar el error con detalle
2. Parchear el código / regla / flujo
3. Actualizar memoria/documentación (.md) – crea o edita un archivo como LESSONS-LEARNED.md o el correspondiente
4. Re-verificar el fix

La documentación de lecciones es tan importante como el código mismo.
