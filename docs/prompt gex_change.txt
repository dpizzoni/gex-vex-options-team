# PROMPT PARA ANTIGRAVITY
## Nueva funcionalidad: Gamma Regime Engine

---

## Instrucción general

El sistema actual ya calcula correctamente:

- GEX Matrix
- VEX Matrix
- King Node
- Net GEX / Net VEX
- Dealer Analysis
- Escenarios de absorción
- Dominancia
- Persistencia

**NO modificar ninguna de estas funcionalidades.**

Agregar un nuevo módulo independiente llamado **Gamma Regime Engine**.

---

## Objetivo

Detectar automáticamente cambios de régimen de gamma usando:

1. **Histórico diario de Net GEX** (gráfico — pasado)
2. **Term structure de GEX por expiración** (tabla de UW — forward)

El objetivo **NO** es predecir dirección del precio.

El objetivo es detectar cambios esperados en:
- volatilidad realizada
- comportamiento de hedging del dealer
- probabilidad de trend day vs mean reversion
- probabilidad de compresión vs expansión
- sensibilidad a noticias y catalizadores
- probabilidad de pinning

---

## Fundamento teórico

### GEX positivo → Dealers Long Gamma

```
Precio sube → dealers venden (frenan el movimiento)
Precio baja → dealers compran (frenan el movimiento)
```

Consecuencias esperadas:
- compresión de rango
- absorción de movimientos
- pinning cerca del King Node
- mean reversion intradía
- menor volatilidad realizada

### GEX negativo → Dealers Short Gamma

```
Precio sube → dealers compran (amplifican el movimiento)
Precio baja → dealers venden (amplifican el movimiento)
```

Consecuencias esperadas:
- expansión de rango
- trend days sostenidos
- ruptura más fácil de niveles técnicos
- gaps con seguimiento
- mayor volatilidad realizada
- mayor sensibilidad a noticias y catalizadores

### Regla crítica — NO confundir régimen con dirección

```
GEX > 0 ≠ bullish
GEX < 0 ≠ bearish
```

El signo del GEX describe el **régimen de volatilidad** y el **comportamiento del dealer**.
La dirección del precio es independiente del régimen.

## Base de datos histórica

Guardar diariamente (proceso nocturno, junto al scraping de OI existente):

```
date          — YYYY-MM-DD
ticker        — símbolo
spot          — precio de cierre
call_gex      — GEX total de calls
put_gex       — GEX total de puts
net_gex       — call_gex + put_gex
call_vex      — VEX total de calls
put_vex       — VEX total de puts
net_vex       — call_vex + put_vex
king_node     — strike con mayor |GEX| del día
ema3_net_gex  — EMA de 3 días de net_gex (calculado al guardar)
```

Mínimo de historial requerido para activar el módulo: **20 sesiones** (sin historial suficiente, mostrar "datos insuficientes").

## Variables derivadas

### Régimen

```
regime =
  ema3_net_gex >= 0
    ? "LONG_GAMMA"
    : "SHORT_GAMMA"
```

Usar **EMA3 del net_gex**, no el valor crudo del día.
Esto evita falsas señales cuando el GEX oscila cerca de cero.

### Delta GEX

```
delta_gex = net_gex[hoy] - net_gex[ayer]
```

### Regime Shift

```
regime_shift =
  regime[hoy] !== regime[ayer]
  AND abs(ema3_net_gex[hoy]) > threshold_minimo
```

El `threshold_minimo` evita detectar cruces de régimen cuando el GEX está
prácticamente en cero (sin señal real). Definir como:

```
threshold_minimo = 0.10 × rolling_avg_abs_net_gex(30d)
```

### Shift Strength (normalizado)

```
shift_strength_norm =
  abs(delta_gex) / rolling_avg_abs_net_gex(30d)
```

Clasificación:
```
< 0.25   → Bajo
0.25–1.0 → Moderado
1.0–2.5  → Alto
> 2.5    → Extremo
```

Este método escala automáticamente para cualquier ticker
(NKE, SPY, TSLA, QQQ) sin parámetros manuales.

### Duración del régimen actual

```
regime_duration =
  número de sesiones consecutivas con el mismo regime
  contadas desde el último regime_shift
```

### Gamma Stability Score

```
rolling_window = 20  // sesiones; configurable por ticker

gamma_stability =
  sessions_same_regime_in_window / rolling_window
```

Clasificación:
```
0.0–0.20  → Muy inestable (régimen cambia frecuentemente)
0.20–0.50 → Inestable
0.50–0.80 → Estable
0.80–1.00 → Muy estable (régimen sostenido)
```

## Umbrales EXTREME (basados en distribución histórica propia del ticker)

Calcular sobre los últimos 30 días de historial:

```
p10_net_gex = percentil_10(net_gex, 30d)
p90_net_gex = percentil_90(net_gex, 30d)
avg_abs_vex_delta = rolling_avg(abs(delta_net_vex), 10d)
```

### Condición EXTREME NEGATIVE

```
net_gex < p10_net_gex
AND abs(spot - king_node) > 2 × gridStep
AND delta_net_vex > 0 por 2+ días consecutivos
```

### Condición EXTREME POSITIVE

```
net_gex > p90_net_gex
AND abs(spot - king_node) < 1 × gridStep
```

---

## Régimen conjunto GEX-VEX

Calcular en tiempo real para cada sesión:

```
vex_pressure = abs(net_vex) / max(abs(net_gex), epsilon)
```

Usar los mismos umbrales de Presión existentes en el sistema: < 0.05 / 0.05–0.20 / > 0.20

Cruzar régimen GEX con nivel de presión VEX para clasificar en 4 cuadrantes:

| GEX Regime | VEX Pressure | Cuadrante | Expectativa operativa |
|------------|-------------|-----------|----------------------|
| LONG_GAMMA | Bajo (< 0.05) | Pin Estable | Compresión sostenida. Mayor probabilidad de cierre ATM |
| LONG_GAMMA | Alto (> 0.20) | Pin Frágil | Absorción bajo presión de IV. Si aparece catalizador, ruptura posible |
| SHORT_GAMMA | Bajo (< 0.05) | Direccional Controlado | Trend day sin aceleración extrema |
| SHORT_GAMMA | Alto (> 0.20) | Aceleración Explosiva | Gaps, movimientos violentos con seguimiento. Máxima precaución |

Mostrar el cuadrante activo en el bloque visual.

## Módulo de inferencia forward (tabla de expirations UW)

Usar los datos de la tabla de UW (call_gex, put_gex, net_gex, p_c_ratio por fecha futura).

**Este módulo no predice precio. Infiere cómo podría evolucionar el régimen
a medida que venzan las expirations actuales.**

### Paso 1 — Net GEX forward acumulado

```
net_gex_forward =
  suma de net_gex de todas las expirations > hoy
  (excluyendo la expiración más próxima que vence)
```

Si `net_gex_forward` tiene signo opuesto al `net_gex` de hoy:
la estructura forward anticipa presión hacia un cambio de régimen.

### Paso 2 — Days to Pressure

```
days_to_pressure =
  sesiones hasta que la expiración con mayor net_gex absoluto venza

  Si esa expiración tiene net_gex positivo y es la que sostiene
  el régimen LONG_GAMMA actual:
    al vencer, el net_gex total podría caer / cambiar de signo
```

### Paso 3 — P/C GEX ratio forward

```
pc_forward_trend =
  promedio de p_c_ratio de las próximas 3 expirations
```

```
pc_forward_trend > 1.2  → puts dominando forward → presión hacia SHORT_GAMMA
pc_forward_trend < 0.8  → calls dominando forward → presión hacia LONG_GAMMA
0.8–1.2                 → equilibrado → sin señal
```

### Output del módulo forward

```
FORWARD REGIME SIGNAL:

Régimen actual:    LONG_GAMMA
Régimen forward:   presión hacia SHORT_GAMMA
Days to pressure:  3 sesiones (vence expiración 2026-07-18 con GEX +1.8M)
P/C forward:       1.41 (puts dominando)

Interpretación:
El régimen actual está sostenido principalmente por la expiración del viernes.
Al vencer, la estructura forward es negativa. La transición de régimen
no es inminente hoy, pero la presión estructural se acumula.
```

## Alertas

### LONG GAMMA ENTRY

**Condición:**
```
regime[ayer] = SHORT_GAMMA
regime[hoy]  = LONG_GAMMA
abs(ema3_net_gex[hoy]) > threshold_minimo
```

**Alerta:**
```
[LONG GAMMA ENTRY]
Ticker: {ticker} | {date}

El activo entró en régimen LONG GAMMA.
Shift Strength: {clasificación} ({shift_strength_norm:.2f}×)

Esperar:
- menor volatilidad realizada
- mayor absorción intradía
- probabilidad elevada de pinning near King Node ({king_node})
- menor sensibilidad a noticias
- mayor probabilidad de reversión intradía ante movimientos bruscos
```

### SHORT GAMMA ENTRY

regime[ayer] = LONG_GAMMA

abs(ema3_net_gex[hoy]) > threshold_minimo
```

**Alerta:**

[SHORT GAMMA ENTRY]
Ticker: {ticker} | {date}

El activo entró en régimen SHORT GAMMA.
Shift Strength: {clasificación} ({shift_strength_norm:.2f}×)

Esperar:
- expansión de volatilidad realizada
- mayor probabilidad de trend days sostenidos
- ruptura más fácil de soportes y resistencias técnicas
- mayor sensibilidad a noticias y catalizadores
- mayor probabilidad de gaps con seguimiento
```

### EXTREME NEGATIVE GAMMA

**Condición:**
```
net_gex < p10_net_gex
AND abs(spot - king_node) > 2 × gridStep
AND delta_net_vex > 0 por 2+ días consecutivos
```

**Alerta:**
```
[EXTREME NEGATIVE GAMMA]
Ticker: {ticker} | {date}

Estructura compatible con evento de aceleración.

Net GEX: {net_gex} (percentil {pct:.0f}% histórico 30d)
Distancia al King: {dist_king:.1f} pts ({n_grids:.1f}× gridStep)
VEX aumentando: {n} sesiones consecutivas

La combinación de gamma negativo extremo + spot alejado del King
+ presión VEX creciente es la estructura más propensa a movimientos
violentos si aparece un catalizador.
```

---

### EXTREME POSITIVE GAMMA — PIN ALERT

**Condición:**
```
net_gex > p90_net_gex
AND abs(spot - king_node) < 1 × gridStep
```

**Alerta:**
```
[EXTREME POSITIVE GAMMA — PIN ALERT]
Ticker: {ticker} | {date}

Estructura compatible con evento de pinning.

Net GEX: {net_gex} (percentil {pct:.0f}% histórico 30d)
Distancia al King: {dist_king:.1f} pts

La estructura favorece máxima absorción alrededor del King Node ({king_node}).
Probabilidad elevada de cierre de sesión cerca de ese nivel.
```

---

### FORWARD REGIME PRESSURE (nueva — desde tabla UW)

**Condición:**
```
signo(net_gex_forward) ≠ signo(net_gex[hoy])
AND pc_forward_trend fuera del rango [0.8, 1.2]
AND days_to_pressure <= 5
```

**Alerta:**
```
[FORWARD REGIME PRESSURE]
Ticker: {ticker} | {date}

La estructura forward anticipa presión hacia cambio de régimen.

Régimen actual:      {regime}
Presión forward:     hacia {regime_opuesto}
Días hasta presión:  {days_to_pressure} sesiones
P/C forward:         {pc_forward_trend:.2f}

Interpretación:
Al vencer la expiración del {fecha_clave} (GEX: {gex_clave}),
la estructura de dealer podría cambiar de régimen.
Esto no es una predicción de precio. Es una advertencia
de que el entorno operativo puede cambiar próximamente.
```
